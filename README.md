# 📌 Featured Project
## 📊 Bank of America Consumer Complaint Analysis Dashboard

This project analyzes 62,516 customer complaints submitted between 2017 and 2023 using a synthetic dataset modeled after Bank of America. The objective was to identify complaint patterns, evaluate customer service performance, and provide actionable recommendations to improve customer satisfaction and operational efficiency.

## Project Highlights

- Cleaned and transformed data using Microsoft Excel and Power Query.
- Built an interactive two-page Power BI dashboard.
- Developed custom DAX measures to monitor key performance indicators.
- Analyzed complaint trends by product, issue, state, submission channel, and response performance.
- Generated business-focused insights and recommendations for operational improvement.

## Key Business Questions
- Which financial products generate the highest number of complaints?
- Which states record the highest complaint volumes?
- What issues are reported most frequently?
- How effective is the company's complaint response process?
- How have complaint trends changed over time?
